# 上课啦签到（HDU skl quicksign）

杭电「上课啦」课堂签到（skl.hdu.edu.cn）安卓助手：自动登录 + 4 位签到码快速输入，把 15 秒签到窗口里的时间省下来，只做一件事——听老师报码、输码、滑滑块。

> 纯 Kotlin 原生实现，零第三方依赖。仅用于个人正常到课签到，请确保本人在场。

## 功能

- **自动登录**：数字杭电统一认证（cas → sso）自动填表登录，验证码/滑块手动完成一次
- **语音签到**：MiMo 云端 ASR（可选，需 API Key）+ 综合判断提取签到码，持续切片监听
- **手动输入**：内置大数字键盘，输满 4 位自动提交（网页没就绪先缓存，就绪自动补输）
- **定位/时钟面板**：实时经纬度（20 秒节流）、秒级时钟、当前课程/下一节课提醒（ICS 课表导入，一次永久保存）
- **5 种主题风格**：default / apple / claude / tesla / spotify，黑白模式自适应
- **开屏 Splash**：品牌色开屏，期间后台并行加载登录
- **Debug 导出**：调试日志 + 页面抓取详情，导出到 Download 目录便于反馈问题

## 构建

```
gradlew.bat assembleRelease --no-daemon
```

APK 输出：`app\build\outputs\apk\release\app-release.apk`

工程路径不能含中文（AGP 限制）。
