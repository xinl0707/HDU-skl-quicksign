# 上课啦签到（HDU skl quicksign）

杭电「上课啦」课堂签到（skl.hdu.edu.cn）安卓助手：自动登录 + 4 位签到码快速输入，把 15 秒签到窗口里的时间省下来——听老师报码、输码、过验证，交给本 App 完成重复操作。

> 纯 Kotlin 原生实现，零第三方依赖。仅用于个人正常到课签到，请确保本人在场。
> 详细条款见 [免责声明](#免责声明)，安装使用即视为同意。

## 功能特性

- **自动登录**：数字杭电统一认证（cas → sso）自动填表登录，支持账号密码加密存储（Keystore）、自动重登、SSO 循环防护
- **语音签到**：可选接小米 MIMO 云端 ASR（需 API Key），持续切片监听 + 语言模型综合判断提取签到码，支持跨切片断码与同音字处理
- **手动输入**：内置大数字键盘，输满 4 位自动提交；网页未就绪时先缓存，就绪后自动补输
- **签到结果判定**：提交后检测页面跳转（5 秒超时判定 + 后台缓冲复核），无效弹窗 / 签到成功彩带覆盖页
- **定位 / 时钟面板**：实时经纬度（保留一位小数）、秒级时钟、当前课程 / 下一节课提醒（ICS 课表导入，一次导入永久保存）
- **首次引导**：免责声明（须滑动到底同意）+ 权限引导 + 设置页三步流程，WebView 延迟至保存后加载避免时机问题
- **5 种主题风格**：墨青（默认）/ 朱砂·国潮 / 原木·暖阳 / 石墨·极简 / 极光·青绿，明暗模式自适应
- **开屏 Splash**：品牌色开屏，期间后台并行加载
- **调试导出**：调试日志 + 页面抓取详情，导出到 Download 目录便于反馈问题
- **签到记录**：本地留存每次签到（成功/码无效/输入失败），含课程、时间、方式、考勤与网页截图（离屏生成，不影响签到），列表 + 详情页可回看

## 工作原理

### 登录链路

1. 启动后加载签到首页，后台 HTTP 探测登录态（携带 WebView Cookie 与 sessionId）
2. 未登录时进入统一认证页（sso.hdu.edu.cn），自动填入学号密码，提示手动点击登录（不自动提交，避免按钮点击不稳定）
3. 登录成功后回跳签到页，自动切回键盘面板，全程按屏幕尺寸判定移动端布局

### 语音识别（MIMO）

1. 自动监听默认开启：录音线程持续写入 10 秒环形缓冲区，首个切片等 6 秒上传，之后每 3 秒取最近 10 秒（重叠 7 秒）上传 MIMO 转写
2. 本地快速路径：转写文本直接含连续 4 位标准数字（含中文数字字）立即提取提交
3. 语言模型综合判断：累积转写交给模型提取 4 位码，处理跨切片断码（"2"+"588"=2588）与同音字干扰（八→百/吧）
4. 离开签到界面、切后台、无效弹窗或成功覆盖页显示期间一律停止监听

## 使用说明

1. 首次启动：阅读免责声明并滑动到底同意 → 授予麦克风 / 定位权限 → 进入设置页
2. 右上角「保存」：填写学号密码后点保存，返回主界面即开始自动登录流程
3. 语音识别：设置 → 语音识别引擎 → MIMO，填入 MIMO API Key（mimo.mi.com 控制台获取），开启「自动语音监听」
4. 课表：设置 → 课表 → 导入课表（ICS），可至杭电助手课表订阅下载
5. 签到：老师报码后直接说四位码（语音）或键盘输入，输满自动提交；结果以页面跳转判定为准

## 构建

```
gradlew.bat assembleRelease --no-daemon
```

APK 输出：`app\build\outputs\apk\release\app-release.apk`

要求：Android SDK（compileSdk 37 / minSdk 26），工程路径不能含中文（AGP 限制）。零第三方依赖，无需配置额外仓库。

## 目录结构

```
app/src/main/java/dev/xinl0707/quicksign/
├── MainActivity.kt      主界面：签到面板 / 键盘 / 登录探测 / 轮询状态机 / 结果判定 / 首次引导
├── SettingsActivity.kt  设置页：账号 / 语音 / 课表 / 风格 / 调试
├── CredentialStore.kt   加密存储（Keystore）与偏好
├── SignInjector.kt      注入 JS：页面状态探测 / 自动登录填表 / 四位码盲输
├── MiMoSpeechEngine.kt  MIMO 云端 ASR：录音环形缓冲 / 切片上传 / 语言模型提取
├── ScheduleParser.kt    ICS 课表解析
├── ThemePalette.kt      5 套主题色板
└── DebugLog.kt          调试日志
```
